# **App Name**: QuantEasy

## Core Features:

- Project Setup: Set up projects with units, detailing project info and linking to units.
- BOQ Generator: Quickly generate Bills of Quantities from pre-defined trade templates.
- Claims System: Enable subcontractors to submit claims which Quantity Surveyors can approve, tied to specific BOQ items.
- Payment Certificate Generation: Generate PDF payment certificates with approved quantities, amounts and project details.
- AI Rate Suggestion: Suggest rate by providing up-to-date cost estimates from various suppliers based on market data. This is implemented as a tool.
- User Authentication: Provide login/authentication via email/password and Google Auth.
- PWA Support: Progressive Web App support, enabling offline access and installation on mobile devices.

## Style Guidelines:

- Primary color: Sky blue (#73BEE3) to convey trust and professionalism within the construction domain.
- Background color: Very light blue (#F0F8FF), offering a clean, non-distracting backdrop.
- Accent color: Teal (#3EB489) to highlight key actions and elements with a touch of vibrancy.
- Body and headline font: 'Inter' (sans-serif) for a modern, machined, objective, neutral look.
- Code font: 'Source Code Pro' (monospace) for displaying code snippets.
- Use clear, modern icons representing construction elements, project management, and financial transactions.
- Clean and intuitive layouts, emphasizing data clarity and easy navigation.
